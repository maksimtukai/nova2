# Nova Studio

Application source files for the Nova Studio project.

## Setup

1. Copy `.env.example` to `.env` and set a unique `ADMIN_KEY`.
2. Install dependencies with `npm install`.
3. Start the server with `npm start`.
4. Optional: set `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` to receive a Telegram message when a new visitor session starts.

Password changes require the account email and current password. Email-based password recovery is not configured.
